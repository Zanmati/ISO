# Training Planner

## Автор
Салим Молонашхов

## Описание
Приложение для планирования тренировок с графическим интерфейсом.

Функции:
- Добавление тренировок
- Фильтрация по типу и дате
- Сохранение и загрузка JSON
- Проверка корректности ввода

## Пример использования
1. Введите дату: 2026-05-04
2. Тип: Кардио
3. Длительность: 30
4. Нажмите "Добавить"

## Тесты
- Проверка неверной даты (2026-99-99)
- Проверка отрицательной длительн
